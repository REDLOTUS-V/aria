ARIA — AI Chat Application

Native Android chat app powered by the Gemini API. Kotlin + Jetpack Compose.

Download the latest release

Features
Streaming responses via SSE (Flow-based, token-by-token)
Multimodal input — text + image
Persistent, per-conversation history (Room, cascading deletes)
Retry on failed sends, copy-to-clipboard on replies
Real Room schema migrations (no data loss on updates)
Stack

Kotlin · Jetpack Compose · Room · Hilt · Retrofit · OkHttp · Kotlin Serialization · Gemini API · Coil · MVVM · Flow/StateFlow

Setup
Clone the repo
Add your Gemini API key (see NetworkModule)
Run in Android Studio

Or just grab the APK.
